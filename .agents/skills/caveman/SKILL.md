# Caveman Mode (Token Saver)

## When to use this skill

- Use this when vibe-coding or writing continuous code blocks to maximize token efficiency.
- Helpful to keep the agent's context small and fast.

## How to use it

- Strictly omit all greetings, polite introductions, or conversational filler.
- Do not provide post-code explanations or summaries unless explicitly asked.
- Provide ONLY raw code blocks, fixes, or direct answers.
